# 管家仅管理直属子会话

用户于 2026-09-06 确认，一期管家通过 MCP 仅能查询和操作自己创建的直属子会话。该限制适用于列表、状态、结果、发送消息和取消操作；下一层管家自行管理其直属子会话，保持委派职责明确。

此决策将设计 v2 的默认父会话筛选收紧为操作范围约束，排除通过取消筛选访问项目内其他会话。该约束针对 MCP 管理能力；原生编码助手本身的文件与命令权限遵循下述继承规则。

子会话继承父会话的权限上限。需要权限审批或用户回答时，由用户在子会话中处理，管家获知等待状态；一期不增加管家代答工具。跨 provider 的具体权限映射在规格阶段按实际能力核对，不能提升权限。

2026-09-07：[ADR 0005](0005-transient-child-sessions-and-manager-decisions.md) 替代上述用户进入子会话处理问题及禁止管家代答的约定。直属范围与权限上限保持有效；新交互尚待实现。
