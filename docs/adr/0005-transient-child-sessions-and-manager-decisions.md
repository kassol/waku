# 子会话临时执行与管家统一交互

2026-09-07，用户确认主会话承担日常交互和最终交付；子会话用于分担上下文和并行执行。子会话完成生命周期后归档并从日常会话列表隐藏，完整记录保留，主会话留下执行摘要与可追溯入口。此决策延续 ADR 0001 的历史保留要求。

子会话的问题统一交给管家。管家根据用户目标及已有授权处理技术选择和已授权操作；新增范围、费用或权限需求由管家在主会话集中询问用户。派发前明确可预见的约束，执行中出现的问题按同一授权边界处理。此决策替代 ADR 0002 中“由用户在子会话中处理、管家不代答”的交互约定；直属管理范围和权限上限继续有效，管家代决不产生新的权限授权。

归档发生在结果已由管家接管、摘要与成果证据可靠保存且无需该子会话继续处理之后。一次轮次结束不能单独作为生命周期完成依据。失败任务由管家决定重试、替代或终止，并保留失败原因。会话归档与 Git 资源清理分别判断，无法安全清理的资源继续保留并在主会话说明原因。

这是已确认的产品方向，尚未实现。下一阶段规格需定义摘要内容、归档恢复、问题与审批转交、权限核验及崩溃恢复；历史子会话如何纳入归档另行明确，本轮不迁移或删除既有会话。
