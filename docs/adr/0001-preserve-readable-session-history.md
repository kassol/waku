# 保留用户可读的会话历史

用户于 2026-09-06 确认，会话历史保留到用户主动删除。内部事件日志可按保留策略清理，但清理前必须保全用户可读历史，以控制日志占用并避免长会话或长期未打开 App 导致历史丢失。

此决策取代设计 v2 中直接按事件条数和天数删旧行的无条件做法。历史本身仍会持续占用磁盘。

持久化持续失败时，停止受影响任务并拒绝新任务，保留可恢复数据，明确报告尚未保存的内容。队列压力不能通过静默丢弃转录解决。

突发进程崩溃或断电时，保证恢复已确认保存的内容。流式内容可短暂处于待保存状态，界面必须明确显示保存状态；尚未确认保存的尾部内容可能丢失。正常退出等待保存完成，失败时明确报告。
